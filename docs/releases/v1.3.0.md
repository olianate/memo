## 重要变更

- **正文改为 Markdown 单一来源**：备忘录正文现在按用户输入的 Markdown 原样保存，不再以 Notion 块结构（`body_json`）作为存储格式。搜索文本、摘要、统计和内容哈希都在保存时从 Markdown 派生。
- **需要重置本地资料**：旧版本创建的本地资料存的是块结构，本版本无法读取，启动时会明确拒绝并提示重置本地数据。Notion 中的内容不会被删除，但本地未同步的草稿会丢失；升级前请先导出备份。
- **Notion 不再承诺完全保真**：支持的基本 Markdown（标题、段落、列表、待办、引用、代码块、分隔线、常用行内样式、附件）会映射为 Notion 块；表格、HTML、数学公式、脚注、嵌入等不支持的语法在本地保持原文，推送时作为普通文本或代码块保留。从 Notion 拉取时不会丢弃任何块：有文字的未知块变成段落，无法用 Markdown 表示的块保存为 ` ```notion ` 代码块并可直接看到原始 JSON。

## 新增

- **Obsidian 风格实时预览编辑器**：光标所在行显示 Markdown 原文，离开后自动渲染；点击已渲染的行可回到原文编辑，并尽量把光标放到点击位置。编辑区只有实时预览，没有单独的整篇源码模式；标签显示在编辑框顶部。
- **Markdown 输入**：支持标题 1–6、段落、无序/有序/待办列表、引用、围栏代码块（``` 或 ~~~）、分隔线，以及加粗、斜体、删除线、行内代码和链接。
- **附件仍是 Markdown 引用**：图片和文件以 `![名称](attachment://id)`、`[名称](attachment://id)` 保存在正文中，预览时解析，只有同步到 Notion 时才上传或下载字节。
- **时间线直接预览 Markdown**：列表中的备忘录会渲染标题、列表、引用、代码、表格和附件等常见语法，不必先打开编辑面板。

## 优化

- **保存/换行快捷键可切换**：默认 Enter 保存、Shift+Enter 换行；在设置中可改为 Enter 换行、Shift+Enter 保存，编辑器、快速记录和编辑面板统一生效。
- **可清空本地日志**：设置 → 错误日志中可确认后删除全部同步事件和界面错误记录；之后的日志仍会正常写入。
- 保存不会改写正文：空行、行尾空格和不支持的语法都按原样保留。
- 撤销/重做、跨行移动、合并和 IME 输入在实时预览下不会破坏正文。
- MCP 的 `create_memo` / `update_memo` 直接接收 Markdown 正文并原样写入；备份导出的数据库可在新版本中逐字节恢复正文。
