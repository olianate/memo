## 新增

- **MCP 服务**：设置页新增「MCP 服务」卡片，可启用本地 MCP 服务并配置端口（默认 `8765`）。服务使用 Streamable HTTP 传输，地址为 `http://127.0.0.1:<port>/mcp`，仅监听本机回环地址。
- **MCP 工具**：提供 `search_memos`、`create_memo`、`update_memo`、`delete_memo` 四个工具，可搜索、新建、修改和删除备忘录；内容使用 Markdown，删除会移入本地回收站。
- **MCP 图片与附件**：`create_memo` 和 `update_memo` 支持通过本机路径或 base64 添加图片和文件，并可从记录中移除指定附件；修改正文时默认保留未显式移除的附件。
- **备忘录链接**：编辑器工具栏新增「插入链接」，可为选中文字添加链接；时间线中的链接可直接点击并用系统浏览器打开，支持 `http(s)`、`mailto` 和自动补全裸域名，并拒绝危险协议。

## 修复

- 修复同步完成后顶部仍停留在「正在同步 · 0 条待推送」提示条的问题。拉取开始和结束时现在都会推送同步状态，提示条会在同步结束后正常消失。
