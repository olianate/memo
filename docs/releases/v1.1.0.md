## 新增

- **错误日志中心**：设置页新增「错误日志」卡片，可查看最近的前端与后端异常，并支持刷新、复制和导出。导出日志同时包含 `sync.log` 与 `errors.log`。
- **全局错误兜底**：主窗口与便签窗口都增加了错误边界。未捕获的渲染异常、脚本错误和 Promise 拒绝会写入日志，并显示可恢复的错误页面，而不是整页空白。
- **侧边栏伸缩**：顶栏新增侧边栏开关，可收起或展开左侧栏；状态会保存在本地，重启应用后保持。
- **Notion 连接诊断**：令牌验证、页面/数据库解析、schema 预览、连接和断开操作都会记录脱敏后的操作日志，便于定位失败原因。

## 修复

- 修复 Notion 配置向导在令牌验证后进入目标选择时出现白屏的问题。后端 schema 预览现在始终返回空数组而不是 `null`，前端也增加了空值兜底。
- 修复目标数据库已包含全部 memo 属性时预览页崩溃的问题；完成页对可能缺失的字段也做了安全显示。
- 修复未捕获的渲染或异步异常导致整个界面空白的问题；现在会展示错误页并提供「重试 / 重新加载」入口，同时记录错误日志。
- 修复日志可能包含 Notion token 等敏感信息的问题。写入和导出前会统一脱敏。

## 优化

- 同步日志与错误日志分开导出；日志文件增加应用版本、导出时间、平台和数据目录信息。
- 设置页卡片布局调整，「关于」卡片跨列展示，信息更易读。
- 移除界面中的 `local-first` 字样，统一为更简洁的产品文案。
- 更新 Wails 生成的 TypeScript bindings，并补充前端、后端的回归测试。
